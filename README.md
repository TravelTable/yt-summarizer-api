# YouTube Video Summarizer API

A FastAPI application that accepts a YouTube video URL, extracts its transcript (using YouTube's captions), summarizes the content using OpenAI's GPT-4, and returns a JSON response containing:

- The original transcript
- A concise summary
- Estimated video categories based on the content

---

## Features

- **Transcript Extraction:** Retrieves the transcript from YouTube videos with available captions.
- **AI Summarization:** Uses OpenAI's GPT-4 to generate a concise summary of the transcript.
- **Content Categorization:** Estimates relevant video categories based on the transcript content.
- **RESTful API:** Simple POST endpoint for integration with other services.

---

## Requirements

- Python 3.8+
- [FastAPI](https://fastapi.tiangolo.com/)
- [Uvicorn](https://www.uvicorn.org/) (for running the server)
- [youtube-transcript-api](https://github.com/jdepoix/youtube-transcript-api)
- [openai](https://github.com/openai/openai-python)
- An OpenAI API key (for GPT-4 access)

---

## Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/yourusername/youtube-summarizer-api.git
   cd youtube-summarizer-api
   ```

2. **Create and activate a virtual environment (optional but recommended):**

   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Install dependencies:**

   ```bash
   pip install -r requirements.txt
   ```

   *Example `requirements.txt`:*
   ```
   fastapi
   uvicorn
   youtube-transcript-api
   openai
   ```

4. **Set your OpenAI API key:**

   - Export your API key as an environment variable:

     ```bash
     export OPENAI_API_KEY='sk-...'
     ```

   - Or create a `.env` file in the project root:

     ```
     OPENAI_API_KEY=sk-...
     ```

## Usage

### Running the API Server

```bash
uvicorn app:app --reload
```

- The API will be available at: `http://127.0.0.1:8000`

---

### API Endpoint

#### `POST /summarize`

**Request Body:**

```json
{
  "youtube_url": "https://www.youtube.com/watch?v=VIDEO_ID"
}
```

**Response:**

```json
{
  "transcript": "Full transcript text...",
  "summary": "Concise summary generated by GPT-4.",
  "categories": ["Education", "Technology"]
}
```

**Error Responses:**

- `422 Unprocessable Entity` for invalid input.
- `404 Not Found` if transcript is unavailable.
- `500 Internal Server Error` for unexpected issues.

---

### Example Request (using `curl`)

```bash
curl -X POST "http://127.0.0.1:8000/summarize" \
     -H "Content-Type: application/json" \
     -d '{"youtube_url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ"}'
```

---

## How It Works

1. **URL Validation:** The API validates the provided YouTube URL.
2. **Transcript Extraction:** Uses `youtube-transcript-api` to fetch the transcript. If unavailable, returns an error.
3. **Summarization:** Sends the transcript to OpenAI's GPT-4 API with a prompt to summarize the content.
4. **Categorization:** Asks GPT-4 to estimate relevant video categories based on the transcript.
5. **Response:** Returns a JSON object with the transcript, summary, and categories.

## Security & Privacy

- The API does **not** store transcripts, summaries, or URLs.
- All processing is done in-memory per request.
- Ensure your OpenAI API key is kept secure.

---

## Limitations

- Only works with videos that have available captions/transcripts.
- Summarization and categorization quality depends on GPT-4 and transcript accuracy.
- Rate limits and costs apply for OpenAI API usage.
